# Portfolio (Angular)

This is an Angular-based portfolio website showcasing my projects and skills. It is a reimplementation of my original portfolio (https://github.com/MaritaThuriAnna/MaritaThuriAnna.github.io) built with Angular to provide a more dynamic and modular structure. The projects are loaded dynamically from a JSON file, and the site includes features like category filtering.

## Features
- **Dynamic Project Loading**: Projects are loaded from `projects.json` and displayed with images, titles, GitHub links, and live demo links.
- **Category Filtering**: Filter projects by category (e.g., Web Application, Utility Tool, UI Component).
- **Responsive Design**: The layout is responsive and matches the original portfolio's styling.
- **Standalone Components**: Built using Angular's standalone components feature, without traditional NgModules.
